    Archive Guide

    How to Use New Eden Archive

    1 Programs

    Create the main school categories, then attach curriculums to each program.

    2 Curriculums

    Build each curriculum, add course requirements, notes, and attachments.

    3 Courses

    Maintain the master course catalog used by curriculum requirements.

    Courses Tab

    Use Courses as the master catalog. Add a course here before attaching it to a curriculum. Search, filter by credits, sort by ID, credit, or course name, and use Edit/Delete actions when admin access is unlocked.

    Curriculums Tab

    Select a curriculum from the top dropdowns to review its overview, notes, attachments, and required courses. Add Curriculum opens a builder where you can create the curriculum and choose course requirements in one place. Manage Requirements is for later edits.

    Programs Tab

    Use Programs for the main school categories. Select a program to see its details on the left and the curriculums that belong to it on the right. Manage Curriculums organizes which curriculums belong under that program.

    Admin Access

    Viewers can search and read archive data. Admins can add, edit, remove, upload attachments, and save changes to Firebase. If a button is hidden, check that Admin is unlocked in the top bar.
